# 🖨️ 3D Printer G-Code Simulator

A modern, interactive **3D Printer G-Code Simulator** that renders, visualizes, and simulates 3D printing paths directly in the browser.

This web application reads standard **3D printer G-code** files and animates the printing process in real time, including the print bed, print head, and extruded filament. It helps users inspect toolpaths, verify layer heights, and preview prints before sending them to a physical 3D printer.

---

## 🚀 Project Overview

This project demonstrates real-world applications of:

- 🌐 Web-Based 3D Graphics & Rendering
- ⚙️ G-Code Parsing & Interpretation
- ⚡ Real-Time Print Motion Simulation
- 🎨 Interactive Material & Color Customization

Users can load built-in sample models or upload their own **`.gcode`** files to visualize layer-by-layer printing with adjustable simulation settings.

---

## ✨ Features

- 🎛️ **Interactive 3D Visualizer**
  - Rotate, pan, and zoom the print bed

- 📂 **Preset & Custom G-Code Support**
  - Built-in sample models
  - Upload your own `.gcode` files

- 📊 **Real-Time Print Telemetry**
  - X / Y / Z coordinates
  - Current layer
  - Line index
  - Printing status

- 🧵 **Filament Customization**
  - PLA material profile
  - Custom filament colors

- ⚡ **Adjustable Simulation Speed**
  - Speed slider for real-time control

- 📏 **Print Settings**
  - Configurable nozzle diameter
  - Adjustable layer height


## ▶️ Run the Project

### Option 1 (Windows)

Simply run:

```bash
run.bat
```

### Option 2 (Python HTTP Server)

```bash
python -m http.server 8080
```

Open:

```

```

## 🕹️ How to Use

### 1. Select a Preset Model

Choose from built-in models such as:

- Cube
- Cylinder
- Pyramid
- Spiral Vase
- Star
- Wave Box

### 2. Upload Custom G-Code

Click **Upload .gcode File** and select any G-code generated by your slicer.

### 3. Customize Printing

Adjust:

- Filament Color
- Material Type
- Nozzle Diameter
- Layer Height

### 4. Control Simulation

Use the speed slider to slow down or speed up the printing process.
